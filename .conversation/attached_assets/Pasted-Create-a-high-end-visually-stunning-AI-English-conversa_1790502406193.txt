Create a **high-end, visually stunning AI English conversation app** called **MIA**.

This is a **frontend-first design task**.

Do not build a generic chatbot dashboard.

Do not make it look like ChatGPT.

Do not make it look like a school English-learning platform.

Do not make it look like a typical SaaS template.

The product should feel like a **premium Gen-Z friendly AI companion app** — warm, aesthetic, personal, elegant and addictive to use.

The entire experience revolves around one AI character:

# MIA

Mia is the user's personal English-speaking companion.

She talks naturally with the user, keeps conversations going, gently corrects English mistakes and helps the user become more confident.

The user should feel:

> **“I'm talking to Mia, not using an English-learning tool.”**

---

# DESIGN DIRECTION

Use a sophisticated **pink + warm beige + ivory + white** palette.

The design should have a soft editorial/lifestyle aesthetic.

Think:

**Pinterest × premium wellness app × modern AI companion**

NOT:

**school app × corporate dashboard × generic AI SaaS**

### Main palette

Background:

* warm ivory
* soft cream
* light beige

Accent:

* blush pink
* dusty rose
* muted rose

Text:

* warm dark brown
* charcoal

Use pink strategically.

Do NOT turn the entire application pink.

The dominant feeling should be:

**cream + white + subtle pink accents.**

Avoid:

* navy
* blue
* purple
* neon
* harsh black
* excessive gradients
* glassmorphism
* excessive shadows
* excessive borders
* excessive cards
* cartoon-style UI
* childish illustrations

---

# TYPOGRAPHY

Use an elegant modern typography combination.

Large headings should feel editorial and premium.

Use a sophisticated serif/display font for selected large headings if it improves the aesthetic, combined with a clean modern sans-serif for UI.

Example feeling:

**“Speak freely.
Grow naturally.”**

Large typography should be one of the major visual elements.

Do not make everything tiny.

---

# GLOBAL LAYOUT

The website should use generous whitespace.

Use asymmetric layouts where appropriate.

Avoid placing everything inside rectangular cards.

Use:

* large typography
* floating elements
* soft organic shapes
* subtle shadows
* large images
* editorial spacing
* curved sections
* subtle pink highlights

The result should feel carefully art-directed rather than generated from a template.

# MIA HERO CHARACTER

Mia must be the visual centerpiece.

Create a beautiful, friendly female AI character/avatar.

She should look:

* modern
* warm
* approachable
* expressive
* stylish
* realistic but slightly artistic

Avoid:

* robotic appearance
* sci-fi appearance
* anime appearance
* childish cartoon appearance

Place Mia inside an elegant organic cream/pink composition.

Around Mia, place 3–4 floating conversation snippets.

For example:

> “Hey! How was your day?”

> “Tell me more 👀”

> “Want to practice something?”

These should float naturally around the character.

Add very subtle floating animation.

Mia's avatar should have a subtle breathing/idle animation.

# IMPORTANT UX RULES

Mia is the emotional center of the product.

The UI should always guide the user back toward:

**Talking with Mia.**

Do not overload the user with statistics.

Do not make English learning feel like homework.

Do not make the app feel like a corporate dashboard.

Do not make the interface look AI-generated.

# FINAL ART DIRECTION

Before considering the design complete, ask:

Does this look like a generic chatbot?

If YES → redesign it.

Does it look like a school English app?

If YES → redesign it.

Does it look like a SaaS dashboard?

If YES → redesign it.

Does Mia feel like the main character?

If NO → redesign it.

Does the pink + beige + white palette feel sophisticated rather than childish?

If NO → redesign it.

The final result should feel like a **premium AI companion product that someone would genuinely want to open every day.**

The emotional feeling should be:

**“I want to talk to Mia.”**

Not:

**“I have to study English.”**
